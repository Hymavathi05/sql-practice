# SQL Practice – Interview Focused

This repository contains my structured SQL practice based on real interview patterns.
Each folder represents one important SQL concept that is frequently asked in
technical interviews (especially for fresher roles like Accenture).

All queries are written and tested on an **Employee** table.

---

## 📂 Folder Structure

| Folder | What it contains |
|------|----------------|
| CREATE_Table_Queries | SQL used to create the Employee table |
| insert_queries | SQL INSERT statements to add employee records |
| select_queries | Basic SELECT queries |
| WHERE_Queries | Filtering using WHERE clause |
| AND_Queries | Using AND for multiple conditions |
| OR_Queries | Using OR conditions |
| NOT_Queries | Using NOT operator |
| BETWEEN_Queries | Filtering using BETWEEN |
| IN_Queries | Using IN operator |
| LIKE_Queries | Pattern matching using LIKE |
| filtering_queries | Combined filtering examples |
| GROUP_BY_Queries | Grouping data using GROUP BY |
| HAVING_Queries | Filtering groups using HAVING |
| AGGREGATE_QUERIES | COUNT, SUM, AVG, MAX, MIN queries |

---

## 🗄️ Employee Table Structure

The practice is based on this table:

- EID – Employee ID  
- EFNAME – First Name  
- ELNAME – Last Name  
- ESAL – Salary  
- EADDRESS – Address
